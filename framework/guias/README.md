# Guias de execução

Uma tarefa por guia. Use os modelos associados para registrar decisões e evidências. Os guias aplicam as definições do [núcleo](../README.md); prazos e metas precisam ser acordados no contexto da empresa.

| Tarefa | Quando usar |
| --- | --- |
| [Priorizar demandas](priorizar-demandas.md) | Fila dispersa ou capacidade insuficiente |
| [Tratar um incidente](tratar-incidentes.md) | Interrupção ou comprometimento suspeito de serviço |
| [Testar restauração](testar-restauracao.md) | Verificar capacidade de recuperar dados e serviço |
| [Entregar uma melhoria](entregar-melhoria.md) | Mudança pequena com saída de negócio verificável |
| [Conduzir uma revisão](conduzir-revisao.md) | Decidir prioridades, recursos e risco |
| [Usar assistência por IA](usar-ia.md) | Preparar ou revisar uma saída, com controle humano |
| [Escolher ferramentas](escolher-ferramentas.md) | Comparar requisitos, custo, operação, integração e saída |
| [Ler os fluxogramas](fluxos-de-trabalho.md) | Consultar decisões, ramificações e retornos da demanda e do incidente |

Para iniciar a rotina inteira: [Primeiros 30 dias](../adocao/primeiros-30-dias.md).
